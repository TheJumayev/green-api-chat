# Как проверить работу приложения

Пошаговая инструкция для проверяющего. Весь путь занимает около 5 минут.

Приложение работает полностью в браузере, без бэкенда, поэтому понадобится
собственный инстанс GREEN-API — чужие учётные данные в него не зашиты.

**Что нужно:**

- аккаунт [GREEN-API](https://green-api.com) — подойдёт бесплатный тариф «Developer»;
- телефон с WhatsApp — его привяжем к инстансу, с него будут уходить сообщения;
- второй номер с WhatsApp (телефон коллеги, рабочий номер) — чтобы ответить
  и увидеть входящее сообщение.

---

## Шаг 1. Создать инстанс

1. Зарегистрируйтесь на [green-api.com](https://green-api.com).
2. В [личном кабинете](https://console.green-api.com/) нажмите **«Создать инстанс»**
   и выберите бесплатный тариф **Developer**.

## Шаг 2. Привязать телефон

1. Откройте созданный инстанс в кабинете — там появится QR-код.
2. На телефоне: **WhatsApp → Настройки → Связанные устройства →
   Привязка устройства** — отсканируйте QR.
3. Дождитесь, пока состояние инстанса станет **`authorized`**.

## Шаг 3. Скопировать учётные данные

В карточке инстанса в кабинете есть два поля:

| Поле               | Выглядит так                  |
| ------------------ | ----------------------------- |
| `idInstance`       | `1101234567`                  |
| `apiTokenInstance` | длинная строка из букв и цифр |

Если в кабинете указан собственный `apiUrl` (например `https://7103.api.greenapi.com`),
скопируйте и его.

## Шаг 4. Войти в приложение

1. Откройте приложение — по ссылке на развёрнутый сервис или локально
   (`npm install && npm run dev`, подробности в [README](../README.md#запуск)).
2. Введите **ID Instance** и **API Token Instance**.
   Если `apiUrl` отличается от стандартного — раскройте **«Дополнительно»**
   и укажите его там.
3. Нажмите **«Войти»**.

Приложение проверит данные методом `getStateInstance` и сразу вызовет
`setSettings`, чтобы включить очередь уведомлений для HTTP API.

> ⏳ После `setSettings` инстанс перезагружается примерно **1–2 минуты**.
> Если первые входящие сообщения не приходят — подождите и обновите страницу.
> Индикатор рядом с заголовком «Чаты» покажет состояние подключения.

## Шаг 5. Начать чат и отправить сообщение

1. Нажмите **«Новый чат»**.
2. Введите номер получателя в международном формате, без `+` и пробелов:
   `998901234567`, `79991234567`. Формат ввода свободный — скобки, пробелы
   и дефисы отбрасываются.
3. Напишите текст и нажмите **Enter** (или кнопку отправки).
   **Shift + Enter** переносит строку.

Сообщение появится в ленте сразу, со значком часов — это оптимистичная
отправка. Как только GREEN-API подтвердит приём, значок сменится на галочку.

## Шаг 6. Получить ответ

Ответьте со второго телефона в WhatsApp на пришедшее сообщение.
Ответ появится в чате автоматически, в течение нескольких секунд —
приложение держит постоянный long polling к `receiveNotification`.

## Что ещё можно посмотреть

| Что                   | Где                                                                                              |
| --------------------- | ------------------------------------------------------------------------------------------------ |
| Светлая / тёмная тема | Иконка солнца или луны в шапке сайдбара                                                          |
| Состояние подключения | Точка рядом с заголовком «Чаты»: зелёная — подключено, синяя — переподключение, красная — ошибка |
| Поиск по чатам        | Поле «Поиск» в сайдбаре                                                                          |
| Повтор при ошибке     | Отключите интернет, отправьте сообщение — появится значок ошибки и кнопка «Отправить ещё раз»    |
| Мобильная вёрстка     | Сузьте окно до ~400px: останется одна панель, в шапке появится «Назад»                           |
| Сохранение истории    | Обновите страницу — чаты и сообщения останутся                                                   |
| Выход                 | Иконка выхода в шапке — очищает учётные данные и историю                                         |
| Доступность           | Пройдите интерфейс только клавишей Tab                                                           |

## Соответствие заданию

| Требование                             | Где проверить                                                                 |
| -------------------------------------- | ----------------------------------------------------------------------------- |
| 1. Интерфейс отправки и получения      | Шаги 5 и 6                                                                    |
| 2. Используется GREEN-API              | `src/api/greenApi.ts`                                                         |
| 3. Только текстовые сообщения          | Медиа и группы отфильтровываются в `src/features/chat/model/reducer.ts`       |
| 4. Внешний вид по прототипу web.max.ru | Токены цветов и радиусов в `src/styles/tokens.css` сняты с интерфейса MAX     |
| 5. Максимально простой интерфейс       | Два экрана, без роутера; в рантайме только `react` и `react-dom`              |
| 6. Отправка методом SendMessage        | `sendMessage()` в `src/api/greenApi.ts`                                       |
| 7. Приём через HTTP API                | `src/api/transport/polling.ts` — `receiveNotification` + `deleteNotification` |
| 8. Технология React                    | React 19, TypeScript strict                                                   |

## Если что-то не работает

| Симптом                                    | Причина и что делать                                                                                                                                                                |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| «Инстанс не авторизован»                   | Телефон не привязан. Отсканируйте QR в кабинете и дождитесь состояния `authorized`                                                                                                  |
| «Неверный idInstance или apiTokenInstance» | Опечатка при копировании. Проверьте оба поля                                                                                                                                        |
| «Инстанс запускается»                      | Инстанс перезагружается после `setSettings`. Подождите 1–2 минуты                                                                                                                   |
| Сообщения уходят, но ответы не приходят    | В кабинете должно быть пустое поле `webhookUrl` и включённые уведомления. Приложение выставляет это само при входе, но после ручной правки настроек проверьте ещё раз               |
| Отправка возвращает ошибку 466 или 403     | Исчерпан лимит бесплатного тарифа либо аккаунт временно ограничен — смотрите кабинет GREEN-API                                                                                      |
| «Не удалось связаться с GREEN-API»         | Нет сети, неверный `apiUrl` либо запросы блокируются CORS. Для локального запуска есть прокси: создайте `.env.local` со строкой `VITE_USE_PROXY=true` и перезапустите `npm run dev` |
| Сообщение приходит дважды                  | Не должно: дедупликация идёт по `idMessage`. Если воспроизвелось — это баг, буду признателен за сценарий                                                                            |

---

## О безопасности

Бэкенда нет: `idInstance` и `apiTokenInstance` хранятся в `localStorage`
браузера и отправляются только на адрес GREEN-API. Для тестового задания это
осознанный компромисс — он описан в [README](../README.md#ограничения).
Кнопка «Выйти» полностью очищает хранилище.

После проверки инстанс можно отвязать в личном кабинете GREEN-API.
